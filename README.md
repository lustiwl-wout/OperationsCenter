# Operations Center

Enterprise aggregated monitoring dashboard for the OC. Designed as a wall display
that surfaces the health of ~15 monitoring tools at once, with a hard visual
emphasis on Priority 1 incidents.

## Stack

- **Node 20 + Express** — serves the dashboard and the `/api/snapshot` feed.
- **Vanilla HTML / CSS / JS** — no build step, ships as-is to Render.
- **PostgreSQL (Neon)** — target datastore; `src/db.js` is a connection stub
  that reads `DATABASE_URL`. Not yet wired into the UI — the current snapshot
  is generated by `src/data.js` for visual development.

## Current scope

This iteration focuses on **visuals**:

- Dark wall-display theme with ambient grid + glow.
- Aggregated overall status pill (healthy → critical) in the top bar.
- KPI strip: P1 / P2 / P3 counts, healthy tools, open incidents, MTTR.
- 15 monitoring source cards with status, latency, uptime, throughput and a
  live sparkline.
- Live alert feed panel, newest first, severity-coded.
- **P1 attention effects**: pulsing full-screen red overlay, striped alarm
  banner with siren icon, pulsing card borders, blinking status chips.

The snapshot feed refreshes every 5s. Pseudo-random but stable per 15s bucket
so the wall tells a coherent story and always has at least one P1 on first
load (for demo purposes).

## Running locally

```bash
npm install
npm start
# http://localhost:3000
```

## Deploying

- **Host:** Render (`render.yaml` provided). `npm install` / `npm start`.
- **DB:** Neon Postgres. Set `DATABASE_URL` on the Render service to the Neon
  pooled connection string; SSL is already configured in `src/db.js`.
